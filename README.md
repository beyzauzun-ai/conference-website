## 📌 About the Project
This project is a dynamic conference website that showcases:
- Event details
- Speakers
- Schedule
- Ticket pricing

It demonstrates how to build and deploy a full-stack web application from scratch.

## 🛠 Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Render (Deployment)
- GitHub (Version Control)

## ✨ Features
- Dynamic data rendering with Flask
- Responsive and modern UI
- Conference schedule & speaker listing
- Pricing section
- Live deployment

## ⚙️ Installation (Local Run)

Clone the repository:
```bash
git clone https://github.com/beyzauzun-ai/conference-website.git
cd conference-website
```

## ⚙️ Install dependencies:

pip install -r requirements.txt

Run the app:

python app.py

Then open:

http://127.0.0.1:5000

## 🚀 Deployment

This project is deployed using Render.
